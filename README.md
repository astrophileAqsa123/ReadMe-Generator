# ReadMe-Generator
=======================

## Overview
The ReadMe-Generator is a full-stack application that simplifies the process of creating high-quality README files.

## Key Features
* Automatic project type detection
* Framework and library detection from files
* Automatic setup steps detection
* Professional markdown generation
* Relevant section inclusion

## Setup
1. Clone the repository: `git clone https://github.com/astrophileAqsa123/ReadMe-Generator.git`
2. Install dependencies: `npm install` (in `frontend` and `server` directories)
3. Start the application: `npm run dev` (in `frontend` directory) and `node index.js` (in `server` directory)
